API 接入说明（WAF 挑战通用协议，不区分 JS 挑战或滑块验证）
1 收到 428
App / 小程序请求 API 时若无有效凭证，WAF 返回 428 Precondition Required，Header 携带 Challenge-Id。
2 完成挑战
打开 WebView 加载 /waf-challenge/init，同时轮询 GET /waf-challenge/status?id={Challenge-Id}。
3 重试请求
状态返回 completed 后关闭 WebView，重试所有 API 请求。Cookie 在有效期内（站长可配置）免重复挑战。
并发请求返回 202 Accepted 表示挑战进行中，无需重复打开 WebView。Cookie 过期后自动重新挑战。
